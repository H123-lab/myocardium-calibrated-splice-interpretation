## Version limitations

Some exact software versions and command-line configurations used during the original analysis are no longer available.

Where the manuscript specifies a version, that version should be retained only if it can be supported by surviving records.

Where the exact version cannot be verified, the repository should explicitly state:

"Version not recovered from the surviving analysis environment."

## Reproducibility principle

Current software versions should not be substituted for historical versions and represented as the versions originally used.

If an independent reconstruction is later performed using current software, it should be labelled as a reconstruction and reported separately from the historical analysis.
