# Example Data

This directory does not contain participant-level clinical or genomic data.

Example files may be added only when they are:

1. legally redistributable;
2. non-identifying;
3. explicitly provided by the originating repository for redistribution; or
4. clearly synthetic and labelled as synthetic.

Synthetic examples must never be presented as observations from the study cohort.

The purpose of example data is to demonstrate file structure, variable names, expected input/output formats, and workflow interfaces.

No synthetic example should be used to substantiate a manuscript numerical result.
