# Data directory

This directory is reserved for data files that may lawfully be redistributed with the repository.

Do not commit raw participant-level data, controlled-access files, direct identifiers, access credentials, or third-party data without confirmed redistribution permission.

Public source datasets should be obtained from their originating repositories. Their accessions and source references will be documented in `docs/provenance.md`.

Any example dataset must be clearly labeled as either:

* synthetic data generated solely for software demonstration; or
* a permitted, documented subset of source data.

No synthetic or example data may be represented as observed study data.
