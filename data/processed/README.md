# Processed data

This directory is reserved for processed outputs that are permitted for redistribution and have been verified against the analysis workflow.

Before adding files, document:

* source dataset(s);
* processing script and version;
* variable definitions and units;
* participant/sample denominator;
* missing-data handling;
* whether the output is observed, derived, or synthetic;
* redistribution status.

Do not place controlled-access participant-level data here.
