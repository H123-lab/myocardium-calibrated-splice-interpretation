## 3. Mandatory Comprehensive Annotation Fields

To track variant coordinates precisely across computational partitions, the underlying database structure relies on 14 discrete annotation domains captured within the master `raw_variant_evidence_registry.tsv` matrix:
1. **Gene Focus Area:** Identifier targeting either the *TTN* or *MYH7* locus.
2. **Transcript Archetype:** Unified reference models tied to GENCODE v38 (**NM_001267550.2** for *TTN*; **NM_000257.4** for *MYH7*).
3. **Genome Assembly Coordinate:** Baseline mapping anchored securely to **GRCh38 (hg38)**.
4. **Genomic Coordinate Location:** Precise chromosome 2 and chromosome 14 base position identifiers.
5. **cDNA Sequence Change:** Human Genome Variation Society (HGVS) `.c` formatting layer.
6. **Protein Consequence:** Predicted translational shift metrics (`HGVS.p`) where clinically applicable.
7. **Exon / Intron Boundary Context:** Structural location flags matching canonical splicing boundaries.
8. **Variant Type Dimension:** Single Nucleotide Variants (SNV) or explicit indel tracking configurations.
9. **Population Frequency Filter:** Population allele frequency parsing pulled directly from **gnomAD v3.1.2** layers.
10. **Biomechanical Domain Mapping:** Localized structural-domain overlays (e.g., Z-disc, I-band, PEVK, Converter, Motor Head, Rod).
11. **Prior Clinical Classification:** Legacy labels derived from public repositories (e.g., ClinVar Variants of Uncertain Significance).
12. **Transcriptomic Splicing Evidence:** Experimentally observed RNA events (e.g., exon skipping, cryptic splice-site activation).
13. **AI-Derived Disruption Metrics:** Probability metrics (0.0 to 1.0) calibrated via **CardioSplice-RU v0.1**.
14. **Comparator Predictor Benchmarks:** Joint reference probabilities generated via SpliceAI v1.3.1 and MaxEntScan.
