# Final analytic cohort

## Reported cohort composition

The manuscript reports:

- Non-failing controls: n = 80
- Dilated cardiomyopathy (DCM): n = 160
- Hypertrophic cardiomyopathy (HCM): n = 120
- Other cardiomyopathies: n = 90
- Total: n = 450

The arithmetic reconciliation is:

80 + 160 + 120 + 90 = 450

## Important provenance limitation

These aggregate counts are reported in the manuscript and are not equivalent to a
reconstructed participant-level source linkage.

The original source-to-final-participant mapping is not currently available.

Therefore, this repository does not claim that every individual participant can presently
be traced from the final cohort back to a specific accession/sample identifier.

Source-level accession metadata are documented independently.

The single-cell resource GSE138262/PRJNA575238 contains 16 sequencing libraries
representing five HCM participants and is treated as a single-cell reference resource,
not as five additional participants in the reported 450-person bulk RNA cohort.
