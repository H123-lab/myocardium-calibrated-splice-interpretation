## 3. Mandatory Evidence Gate (Prior to Manuscript Refinement)
Before any specific controlled-access repository or dataset is officially named in the finalized manuscript draft, at least one piece of verifiable evidence must be recovered and checked off:
- [ ] **Repository Account / Access Record:** Validated user access permissions or institutional portal credentials.
- [ ] **Download History:** Secure transfer logs, server download receipts, or client pull records.
- [ ] **Dataset Accession:** A confirmed, unique identifier string matching the specific data version used.
- [ ] **Data-Use Agreement (DUA):** Signed institutional agreements specifying the exact approved research parameters.
- [ ] **Study-Level Documentation:** Internal lab logs, analysis notes, or protocol drafts tracking the data ingest phase.
- [ ] **Archived Analysis Log:** Runtime console outputs or pipeline logs capturing the input file paths.
- [ ] **Original Source Publication:** Peer-reviewed reference tracking the specific dataset creation and accession bounds.
