# Participant-level source-to-cohort linkage

The manuscript reports a final analytic cohort of 450 individuals:
80 non-failing controls, 160 DCM, 120 HCM, and 90 other cardiomyopathy cases.

The original participant-level linkage file mapping each source-dataset identifier to
the final analytic cohort identifier is not currently available.

Accordingly, this repository does not reconstruct or infer participant-level identities
from aggregate counts, public sample metadata, or manuscript tables.

Public dataset accession information is provided separately in
`01_dataset_inventory.csv`.

Where source repositories provide sample-level identifiers, those identifiers are
considered source metadata and are not represented here as evidence that a particular
sample contributed to the final 450-participant analytic cohort unless that linkage
can be independently verified.

The reported aggregate cohort counts are therefore distinguished from a fully
reconstructed participant-level cohort manifest.

No participant names, direct identifiers, private clinical records, access credentials,
or controlled-access individual-level data are included in this repository.
